# Emby Companion

**简体中文** | [繁體中文](README.zh-TW.md) | [English](README.en.md)

---

**发现影视、浏览媒体库、播放与订阅**

Emby 观影助手是一款 macOS 上的 Emby 媒体库助手，将影视榜单、TMDB 影视与人物资料、你的 Emby 媒体库和 MoviePilot 订阅连接起来。

从榜单、影视搜索或人物作品中找片，直接查看入库与缺集情况。已入库的作品可选择媒体版本、线路和外部播放器观看；未入库的电影或缺集季度，可提交给 MoviePilot 订阅。

本仓库用于发布安装包、使用说明和接收问题反馈。本软件闭源。

[下载最新版](https://github.com/ffinly/emby-companion/releases/latest) · [版本记录](https://github.com/ffinly/emby-companion/releases) · [反馈问题](https://github.com/ffinly/emby-companion/issues)

## 主要功能

### 从榜单发现想看的影视

- 浏览 IMDb、豆瓣、TMDB 热门与本周趋势、影展与奖项等影视榜单，查看作品排名，以及已入库、未入库的情况。
- 在作品详情查看它被哪些榜单收录；点击后直接打开榜单，按榜单原有排序浏览。
- 同步时从 [emby-collection-sync](https://github.com/ffinly/emby-collection-sync) 获取最新榜单范围，跟随上游的新增、修改、删除、分组与排序更新。
- 通过首页“添加自定义片单”接入 TMDB 片单，也可创建个人片单，整理自己的选片范围。

### 查看首页统计与核心榜单入库率

首页分别显示 TMDB 片单与 Emby 媒体库统计。TMDB 面板包含片单总数、预置与自定义片单数量、全部片单的去重作品数及其中已入库数量。

“核心榜单入库率”默认统计第一至第三梯队，点击该指标或“核心榜单设置”可按级别选择，也可单独勾选、排除榜单；支持搜索和对当前结果全选，保存后更新统计。核心范围只影响该入库率，不改变全部片单的作品总数与已入库数量。

### 搜索影视，也能顺着人物找作品

- TMDB 搜索支持中文或原文名称、人物姓名、TMDB 编号三种方式。
- 人物检索覆盖演员（含配音）、导演、编剧、原著、制片、配乐／作曲；进入人物作品页，可查看关联电影、剧集及入库情况。
- 查看作品简介、海报、可用评分、演职人员及人物代表作品，搜索结果支持按媒体类型、入库状态筛选。
- Emby 媒体库内也能搜索人物，查看此人在本库中的相关作品；搜索建议优先展示电影和剧集。
- 详情页提供豆瓣、IMDb 与 TMDB 标识入口。已有条目编号时直接跳转；豆瓣未匹配条目时优先用 IMDb 编号搜索，再按作品名称搜索，IMDb 无编号时按名称搜索。

已匹配 TMDB 的作品，影视资料、人物名单、职务、角色及头像地址统一以 TMDB 为准；未匹配或经 TMDB 确认不存在的作品使用 Emby 资料、人物和图片。TMDB 资料同步与手动刷新只更新应用本地资料，不会改写 Emby 服务器元数据。

### 分别设置界面、片单与资料语言

在“连接与配置 → 语言”设置界面语言、预置片单语言、TMDB 元数据语言及海报语言。界面支持跟随系统、简体中文、繁体中文与英文；片单和元数据可分别跟随界面，也可独立选择三种语言。预置片单的三种语言名称均从上游项目读取。

已匹配的影视与人物资料按所选 TMDB 元数据语言显示，不受 Emby 服务器资料语言限制。不同语言资料分别缓存，切换回来可以复用；切换元数据语言时停止旧语言资料同步，再按新语言继续处理。详情中的“刷新资料”会重新请求当前语言的最新 TMDB 资料，失败时保留已有资料。

媒体库名称支持自动加载预置中英映射，覆盖电影、剧集、纪录片、演唱会、蓝光原盘、少儿、动画等常见名称。英文界面默认开启，中文界面可按需开启；管理窗口自动读取当前账号的媒体库，支持自定义显示名称、清空预置映射或恢复预置。未匹配或留空时保留原名称，仅修改本应用显示，不修改 Emby 服务器。

### 浏览自己的 Emby 媒体库与合集

- 浏览电影、剧集和 Emby 合集，并查看剧集的季、集及可播放版本。
- 按媒体库、媒体类型、国家／地区、发行年份、类型、TMDB 匹配状态及观看状态组合筛选。年代覆盖 1960、1950、1940 年代及 1940 年以前；异常或缺失年份归入“未知”，无数据的区间自动隐藏。
- 筛选项保持原有顺序，超出一行可点“更多”；双击筛选区域空白可快速收起或展开。
- 按名称、添加日期、上映日期、年份或 TMDB 评分排序，快速找到想看的内容。
- 查看和管理已观看、观看中、未观看状态；可开启“隐藏观看记录”，临时隐藏观看状态与进度，关闭后恢复显示。

### 看清哪些已入库、哪些季度还缺集

在榜单、TMDB 搜索和作品详情中核对 Emby 入库情况。剧集可按季度对照 TMDB 集数与 Emby 实际集号，查看已齐或缺失的集数；尚未核对、总集数未知时会单独提示。

### 通过 MoviePilot 订阅缺失内容

连接 MoviePilot 后，可在海报下方订阅未入库电影，或打开季度选择面板订阅缺集的季度。提交时立即展示读取、核对与处理进度，自动跳过已入库电影、集号已齐的季度和已有订阅。

“订阅管理”按电影、剧集分别显示数量与状态，进入后后台刷新，各状态列表均支持滚动加载。支持搜索、手动刷新，以及单独或批量暂停、恢复和取消订阅；已完成记录可单独或批量重新订阅、删除。已订阅作品的右键或角标菜单可直接取消订阅，也可随时进入订阅管理。

MoviePilot 为可选服务，下载和入库由你配置的 MoviePilot 处理。

### 配置多线路 Emby 服务器，调用外部播放器观看

为同一台 Emby 服务器配置多个访问地址，分别选择资料同步主线路与可用播放线路。播放时选择媒体版本、线路和 SenPlayer、Infuse 或 VidHub，即可调用对应播放器。

版本卡片展示文件类型、画质、音轨与字幕数量、文件大小、码率和可识别的压制组；完整文件名与原始文件大小都相同的来源合并展示。点击卡片即可播放；有断点的电影可选择继续或从头播放，剧集默认继续。已经看过的作品再次观看时，仍可按当前断点续播；多版本提供播放时间时优先采用最近一次记录。

分集卡片显示首播日期、简介、观看状态和进度；“播放”设置可控制分集简介及电影压制组是否显示。分集标题与简介按 TMDB 元数据语言显示，一次读取整季，按剧集、季度和语言缓存；缺少对应资料时保留 Emby 内容。可播放文件、观看状态与进度仍来自 Emby。

受支持版本的播放器在正常退出播放页面后回调进度，应用再将进度同步至 Emby。网络异常导致同步失败时，会保留已校验的进度并尝试重试，也可从首页手动重试；同一作品的新播放请求会使旧重试任务失效。具体支持版本见下方[线路与播放器说明](#zh-hans-emby-routes-and-players)。

### 自动同步资料，按需加载图片

完整同步 Emby 媒体库后，自动进行 TMDB 资料同步，获取作品简介、评分、演职人员、库内季度的整季分集资料和海报候选地址。原语言、英文、中文及无语言海报候选一并缓存，图片文件在浏览时按需下载。

作品简介、一句话、片长与演职员资料持久化保存在本地。启动时分级恢复媒体与榜单缓存，人物和搜索索引在后台恢复，已读取的内容可先浏览。

海报语言可选“原语言”“中文”“英文”。候选缓存完整后，切换语言无需再次查询 TMDB；已有图片缓存可直接复用，尚未下载的图片仍需联网加载。旧缓存会在资料同步时补齐缺少的海报候选，无需先清理缓存。

在首页点击“查看同步详情”，可查看各作品最近一次同步的结果、时间和失败原因，并重试失败项。临时网络错误会按策略重试；TMDB 明确未收录的作品使用 Emby 兜底，不计入失败，也不会自动反复查询。

## 下载与安装

- 需要 **macOS 14 或更高版本**。
- 通用 macOS 安装包同时支持 **Apple Silicon 与 Intel**。
- 从 [最新 Release](https://github.com/ffinly/emby-companion/releases/latest) 下载 **Emby-Companion-v1.1.0.dmg**，打开后将 **Emby Companion.app** 拖入 Applications（应用程序）。替换旧版前先退出应用。

请从本仓库的 Releases 获取安装包。应用不会提供影视资源、服务器账号或第三方服务凭证。

### 首次打开：macOS 安全提示

当前软件包使用本地签名，**尚未经过 Apple Developer ID 签名和公证**。首次打开时，macOS 可能提示无法验证开发者或无法验证应用。

确认安装包来自本仓库的 Releases 后，可按以下方式打开：

1. 将应用拖入“应用程序”，先尝试打开一次。
2. 如果被系统阻止，打开 **系统设置 → 隐私与安全性**。
3. 向下找到有关 Emby Companion 的拦截提示，点击 **“仍要打开”**。
4. 按系统提示验证身份，并在再次出现的确认窗口中点击 **“打开”**。

完成后，通常可以直接打开。如果提示应用已损坏、检测到恶意软件，或没有对应的允许入口，请先核对下载来源、重新下载安装包并反馈具体提示，不要将所有拦截都当作同一个签名提示。

参考：[Apple 官方说明：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。不同 macOS 版本的按钮名称可能略有差异；后续版本的签名与公证状态以 Release 说明为准。

## 初次使用

1. 在“连接与配置”填写 Emby 服务器地址并登录。
2. 使用 TMDB 功能前，在 [TMDB API 设置](https://www.themoviedb.org/settings/api) 申请并填写自己的 API Key；请先阅读其 [API 使用条款](https://www.themoviedb.org/api-terms-of-use)。
3. 在首页执行“完整同步媒体库”并同步榜单。媒体库同步后会自动进行 TMDB 资料同步；榜单同步会获取最新榜单配置，完成后默认展开全部榜单分组。可在首页查看同步进度与结果。
4. 安装 SenPlayer、Infuse 或 VidHub，打开已入库作品，选择媒体版本、播放线路与播放器。
5. 如需订阅缺失内容，在 MoviePilot 的“设定 → 系统 → 基础设置”复制 API 令牌，填入应用的 MoviePilot 配置；如需代理，可在设置中配置 TMDB HTTP／SOCKS 代理。

### Emby 服务器线路与播放器

支持配置同一 Emby 服务器的多条访问线路，各线路共用本地媒体库缓存。同步主线路用于读取媒体、剧集文件和合集，播放线路用于播放及单独同步观看记录。可设置默认播放线路；只有一条有效线路时省略线路选择。也可在浏览器打开 `ecplayer://importserver` 链接导入配置，确认前先预览账号与各线路用途；详细格式见“Emby 线路 → 通过链接导入 Emby”。同一服务器与账号复用本地缓存，导入不会清除 TMDB 资料、海报缓存、榜单和 MoviePilot 配置。

| 外部播放器 | 退出播放后回调进度的支持版本 |
| --- | --- |
| SenPlayer | 6.1.1 及以上 |
| Infuse | 8.4.7 及以上 |
| VidHub | 2.3.5 及以上 |

在设置中启用“退出播放器后同步观看进度”，并正常关闭播放器的播放页面。应用收到播放器回调后，将播放进度同步至 Emby；强制退出播放器或没有收到回调时，无法通过该次回调更新进度。播放器需要自行安装，回调能力以对应播放器版本和实际返回结果为准。

Emby、外部播放器与 MoviePilot 需要自行准备。其中 MoviePilot 只用于订阅功能，不是浏览媒体库或调用播放器的前提。

## 版本与更新

在“连接与配置 → 软件更新”查看当前版本和更新检查时间；GitHub 项目、版本发布与问题反馈入口位于“关于应用”。

- **检查更新**：检查 GitHub 最新正式 Release，跳过预发布和草稿。
- **自动检查更新**：应用运行期间每 24 小时检查一次，也可随时手动检查；检查或下载失败后会延后重试。
- **自动下载更新**：启用后自动下载已发现的新版，不会因此直接退出应用。
- **安装更新**：校验通过后，由更新窗口引导安装并重新启动。

更新包使用独立签名和完整性校验。下载或校验失败会停止安装，可重试或前往 GitHub 下载。

## 缓存与数据

“连接与配置 → 缓存与数据”提供三类信息与维护入口：

- **TMDB 缓存**：查看资料、海报和人物图片占用、按元数据语言统计的空间，以及已入库作品关联的 TMDB 人物数量。可清空 TMDB 缓存，也可通过“TMDB 缓存清理”按项目选择清理。
- **Emby 缓存**：查看媒体记录、剧集文件、合集与 Emby 图片数量。清理会移除这些本地记录、Emby 图片、观看记录缓存及相关索引，保留 TMDB 接口资料、海报和人物头像文件。之后可从首页重新同步；连接与登录信息保留，服务器数据不变。
- **本地搜索索引**：根据本地 Emby 作品、合集和人物资料自动维护。搜索异常时可直接重建，无需联网，不修改观看记录。

“TMDB 缓存清理”支持清理其他语言的影视与分集元数据、海报偏好之外的语言图片，以及不再被片单或媒体库引用的缓存。清理其他语言元数据时保留当前语言、海报路径和图片；清理图片时保留当前偏好及回退所需图片，中文海报同时包含简繁两种字形。

连续 7 天未被引用且未新增或更新的缓存，会在引用关系完整、应用空闲时自动清理；其他语言资料不会仅因切换语言就被自动删除。清空 TMDB 缓存后可从首页重新同步榜单与媒体库，图片仍按需下载。正常使用无需手动重建索引。

## 备份与恢复

在“连接与配置 → 备份与恢复”将配置与本地数据导出为加密备份，或从备份文件恢复。

| 备份内容 | 包含的数据 |
| --- | --- |
| TMDB API 配置 | API 地址与 API Key |
| MoviePilot API 配置 | 服务地址与 API 令牌 |
| TMDB 榜单 | 榜单内容、自建片单、片单设置与核心榜单范围 |
| TMDB 缓存 | 影视与人物资料、海报和人物图片 |
| Emby 配置 | 服务器、线路、当前账号、登录令牌及观看记录 |
| Emby 缓存 | 媒体库、合集、分集及 Emby 图片 |
| 使用偏好 | 界面、片单与元数据语言，海报语言、名称映射、播放器及显示偏好 |

导出时可自由勾选需要备份的内容。设置至少 8 个字符的密码并确认后，保存为 `.ecbackup` 文件。

恢复时选择备份文件、输入密码，仅展示文件中包含的项目，并可再次选择恢复范围。配置、榜单与使用偏好会替换本机对应内容；缓存合并，搜索索引自动更新。

核心榜单所选级别与单独勾选、排除项随“TMDB 榜单”一起备份和恢复。仅恢复榜单时，其他未选中的语言、播放与显示偏好保持不变。

观看记录随 Emby 配置备份，仅包含当前账号的观看状态和播放进度。恢复时核对服务器与账号，并保留较新的观看记录。

备份包含 API 密钥与登录信息，请妥善保管文件和密码。

## 联网与隐私

连接信息与缓存保存在本机。应用会根据使用的功能向你配置的服务、TMDB 和 GitHub 发出请求；GitHub 榜单配置与更新请求不携带 TMDB API Key 或 Emby 登录凭证。

反馈问题时请注明应用版本、macOS 版本、操作步骤及错误提示。截图或日志中请隐藏服务器地址、账号、密码、API Key、代理凭证与其他私人信息。
