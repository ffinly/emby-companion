# Emby Companion

[简体中文](README.md) | **繁體中文** | [English](README.en.md)

---

**發現影視、瀏覽媒體庫、播放與訂閱**

Emby 觀影助手是一款 macOS 上的 Emby 媒體庫助手，將影視榜單、TMDB 影視與人物資料、你的 Emby 媒體庫和 MoviePilot 訂閱連接起來。

從榜單、影視搜索或人物作品中找片，直接查看入庫與缺集情況。已入庫的作品可選擇媒體版本、線路和外部播放器觀看；未入庫的電影或缺集季度，可提交給 MoviePilot 訂閱。

本倉庫用於發佈安裝包、使用說明和接收問題反饋。本軟體閉源。

[下載最新版](https://github.com/ffinly/emby-companion/releases/latest) · [版本記錄](https://github.com/ffinly/emby-companion/releases) · [反饋問題](https://github.com/ffinly/emby-companion/issues)

## 主要功能

### 從榜單發現想看的影視

- 瀏覽 IMDb、豆瓣、TMDB 熱門與本週趨勢、影展與獎項等影視榜單，查看作品排名，以及已入庫、未入庫的情況。
- 在作品詳情查看它被哪些榜單收錄；點擊後直接打開榜單，按榜單原有排序瀏覽。
- 同步時從 [emby-collection-sync](https://github.com/ffinly/emby-collection-sync) 獲取最新榜單範圍，跟隨上游的新增、修改、刪除、分組與排序更新。
- 通過首頁“添加自定義片單”接入 TMDB 片單，也可建立個人片單，整理自己的選片範圍。

### 查看首頁統計與核心榜單入庫率

首頁分別顯示 TMDB 片單與 Emby 媒體庫統計。TMDB 面板包含片單總數、預置與自定義片單數量、全部片單的去重作品數及其中已入庫數量。

“核心榜單入庫率”預設統計第一至第三梯隊，點擊該指標或“核心榜單設定”可按級別選擇，也可單獨勾選、排除榜單；支持搜索和對當前結果全選，保存後更新統計。核心範圍只影響該入庫率，不改變全部片單的作品總數與已入庫數量。

### 搜索影視，也能順著人物找作品

- TMDB 搜索支持中文或原文名稱、人物姓名、TMDB 編號三種方式。
- 人物檢索覆蓋演員（含配音）、導演、編劇、原著、製片、配樂／作曲；進入人物作品頁，可查看關聯電影、劇集及入庫情況。
- 查看作品簡介、海報、可用評分、演職人員及人物代表作品，搜索結果支持按媒體類型、入庫狀態篩選。
- Emby 媒體庫內也能搜索人物，查看此人在本庫中的相關作品；搜索建議優先展示電影和劇集。
- 詳情頁提供豆瓣、IMDb 與 TMDB 標識入口。已有條目編號時直接跳轉；豆瓣未匹配條目時優先用 IMDb 編號搜索，再按作品名稱搜索，IMDb 無編號時按名稱搜索。

已匹配 TMDB 的作品，影視資料、人物名單、職務、角色及頭像地址統一以 TMDB 為準；未匹配或經 TMDB 確認不存在的作品使用 Emby 資料、人物和圖片。TMDB 資料同步與手動刷新只更新應用本地資料，不會改寫 Emby 伺服器中繼資料。

### 分別設定界面、片單與資料語言

在“連接與配置 → 語言”設定界面語言、預置片單語言、TMDB 中繼資料語言及海報語言。界面支持跟隨系統、簡體中文、繁體中文與英文；片單和中繼資料可分別跟隨界面，也可獨立選擇三種語言。預置片單的三種語言名稱均從上游項目讀取。

已匹配的影視與人物資料按所選 TMDB 中繼資料語言顯示，不受 Emby 伺服器資料語言限制。不同語言資料分別快取，切換回來可以重用；切換中繼資料語言時停止舊語言資料同步，再按新語言繼續處理。詳情中的“刷新資料”會重新請求當前語言的最新 TMDB 資料，失敗時保留已有資料。

媒體庫名稱支持自動載入預置中英映射，覆蓋電影、劇集、紀錄片、演唱會、藍光原盤、少兒、動畫等常見名稱。英文界面預設開啟，中文界面可按需開啟；管理窗口自動讀取當前帳號的媒體庫，支持自定義顯示名稱、清空預置映射或恢復預置。未匹配或留空時保留原名稱，僅修改本應用顯示，不修改 Emby 伺服器。

### 瀏覽自己的 Emby 媒體庫與合集

- 瀏覽電影、劇集和 Emby 合集，並查看劇集的季、集及可播放版本。
- 按媒體庫、媒體類型、國家／地區、發行年份、類型、TMDB 匹配狀態及觀看狀態組合篩選。年代覆蓋 1960、1950、1940 年代及 1940 年以前；異常或缺失年份歸入“未知”，無資料的區間自動隱藏。
- 篩選項保持原有順序，超出一行可點“更多”；雙擊篩選區域空白可快速收起或展開。
- 按名稱、添加日期、上映日期、年份或 TMDB 評分排序，快速找到想看的內容。
- 查看和管理已觀看、觀看中、未觀看狀態；可開啟“隱藏觀看記錄”，臨時隱藏觀看狀態與進度，關閉後恢復顯示。

### 看清哪些已入庫、哪些季度還缺集

在榜單、TMDB 搜索和作品詳情中核對 Emby 入庫情況。劇集可按季度對照 TMDB 集數與 Emby 實際集號，查看已齊或缺失的集數；尚未核對、總集數未知時會單獨提示。

### 通過 MoviePilot 訂閱缺失內容

連接 MoviePilot 後，可在海報下方訂閱未入庫電影，或打開季度選擇面板訂閱缺集的季度。提交時立即展示讀取、核對與處理進度，自動跳過已入庫電影、集號已齊的季度和已有訂閱。

“訂閱管理”按電影、劇集分別顯示數量與狀態，進入後後台刷新，各狀態列表均支持滾動載入。支持搜索、手動刷新，以及單獨或批量暫停、恢復和取消訂閱；已完成記錄可單獨或批量重新訂閱、刪除。已訂閱作品的右鍵或角標選單可直接取消訂閱，也可隨時進入訂閱管理。

MoviePilot 為可選服務，下載和入庫由你配置的 MoviePilot 處理。

### 配置多線路 Emby 伺服器，調用外部播放器觀看

為同一台 Emby 伺服器配置多個訪問地址，分別選擇資料同步主線路與可用播放線路。播放時選擇媒體版本、線路和 SenPlayer、Infuse 或 VidHub，即可調用對應播放器。

版本卡片展示檔案類型、畫質、音軌與字幕數量、檔案大小、碼率和可識別的壓制組；完整檔案名與原始檔案大小都相同的來源合併展示。點擊卡片即可播放；有斷點的電影可選擇繼續或從頭播放，劇集預設繼續。已經看過的作品再次觀看時，仍可按當前斷點續播；多版本提供播放時間時優先採用最近一次記錄。

分集卡片顯示首播日期、簡介、觀看狀態和進度；“播放”設定可控制分集簡介及電影壓制組是否顯示。分集標題與簡介按 TMDB 中繼資料語言顯示，一次讀取整季，按劇集、季度和語言快取；缺少對應資料時保留 Emby 內容。可播放檔案、觀看狀態與進度仍來自 Emby。

受支持版本的播放器在正常退出播放頁面後回調進度，應用再將進度同步至 Emby。網路異常導致同步失敗時，會保留已校驗的進度並嘗試重試，也可從首頁手動重試；同一作品的新播放請求會使舊重試任務失效。具體支持版本見下方[線路與播放器說明](#zh-hant-emby-routes-and-players)。

### 自動同步資料，按需載入圖片

完整同步 Emby 媒體庫後，自動進行 TMDB 資料同步，獲取作品簡介、評分、演職人員、庫內季度的整季分集資料和海報候選地址。原語言、英文、中文及無語言海報候選一並快取，圖片檔案在瀏覽時按需下載。

作品簡介、一句話、片長與演職員資料持久化保存在本地。啟動時分級恢復媒體與榜單快取，人物和搜索索引在後台恢復，已讀取的內容可先瀏覽。

海報語言可選“原語言”“中文”“英文”。候選快取完整後，切換語言無需再次查詢 TMDB；已有圖片快取可直接重用，尚未下載的圖片仍需聯網載入。舊快取會在資料同步時補齊缺少的海報候選，無需先清理快取。

在首頁點擊“查看同步詳情”，可查看各作品最近一次同步的結果、時間和失敗原因，並重試失敗項。臨時網路錯誤會按策略重試；TMDB 明確未收錄的作品使用 Emby 兜底，不計入失敗，也不會自動反復查詢。

## 下載與安裝

- 需要 **macOS 14 或更高版本**。
- 通用 macOS 安裝包同時支持 **Apple Silicon 與 Intel**。
- 從 [最新 Release](https://github.com/ffinly/emby-companion/releases/latest) 下載 **Emby-Companion-v1.1.0.dmg**，打開後將 **Emby Companion.app** 拖入 Applications（應用程序）。替換舊版前先退出應用。

請從本倉庫的 Releases 獲取安裝包。應用不會提供影視資源、伺服器帳號或第三方服務憑證。

### 首次打開：macOS 安全提示

當前軟體包使用本地簽名，**尚未經過 Apple Developer ID 簽名和公證**。首次打開時，macOS 可能提示無法驗證開發者或無法驗證應用。

確認安裝包來自本倉庫的 Releases 後，可按以下方式打開：

1. 將應用拖入“應用程序”，先嘗試打開一次。
2. 如果被系統阻止，打開 **系統設定 → 隱私與安全性**。
3. 向下找到有關 Emby Companion 的攔截提示，點擊 **“仍要打開”**。
4. 按系統提示驗證身份，並在再次出現的確認窗口中點擊 **“打開”**。

完成後，通常可以直接打開。如果提示應用已損壞、檢測到惡意軟體，或沒有對應的允許入口，請先核對下載來源、重新下載安裝包並反饋具體提示，不要將所有攔截都當作同一個簽名提示。

參考：[Apple 官方說明：在 Mac 上安全地打開 App](https://support.apple.com/zh-cn/102445)。不同 macOS 版本的按鈕名稱可能略有差異；後續版本的簽名與公證狀態以 Release 說明為準。

## 初次使用

1. 在“連接與配置”填寫 Emby 伺服器地址並登入。
2. 使用 TMDB 功能前，在 [TMDB API 設定](https://www.themoviedb.org/settings/api) 申請並填寫自己的 API Key；請先閱讀其 [API 使用條款](https://www.themoviedb.org/api-terms-of-use)。
3. 在首頁執行“完整同步媒體庫”並同步榜單。媒體庫同步後會自動進行 TMDB 資料同步；榜單同步會獲取最新榜單配置，完成後預設展開全部榜單分組。可在首頁查看同步進度與結果。
4. 安裝 SenPlayer、Infuse 或 VidHub，打開已入庫作品，選擇媒體版本、播放線路與播放器。
5. 如需訂閱缺失內容，在 MoviePilot 的“設定 → 系統 → 基礎設定”複製 API 令牌，填入應用的 MoviePilot 配置；如需代理，可在設定中配置 TMDB HTTP／SOCKS 代理。

### Emby 伺服器線路與播放器

支持配置同一 Emby 伺服器的多條訪問線路，各線路共用本地媒體庫快取。同步主線路用於讀取媒體、劇集檔案和合集，播放線路用於播放及單獨同步觀看記錄。可設定預設播放線路；只有一條有效線路時省略線路選擇。也可在瀏覽器打開 `ecplayer://importserver` 鏈接導入配置，確認前先預覽帳號與各線路用途；詳細格式見“Emby 線路 → 通過鏈接導入 Emby”。同一伺服器與帳號重用本地快取，導入不會清除 TMDB 資料、海報快取、榜單和 MoviePilot 配置。

| 外部播放器 | 退出播放後回調進度的支持版本 |
| --- | --- |
| SenPlayer | 6.1.1 及以上 |
| Infuse | 8.4.7 及以上 |
| VidHub | 2.3.5 及以上 |

在設定中啓用“退出播放器後同步觀看進度”，並正常關閉播放器的播放頁面。應用收到播放器回調後，將播放進度同步至 Emby；強制退出播放器或沒有收到回調時，無法通過該次回調更新進度。播放器需要自行安裝，回調能力以對應播放器版本和實際返回結果為準。

Emby、外部播放器與 MoviePilot 需要自行準備。其中 MoviePilot 只用於訂閱功能，不是瀏覽媒體庫或調用播放器的前提。

## 版本與更新

在“連接與配置 → 軟體更新”查看當前版本和更新檢查時間；GitHub 項目、版本發佈與問題反饋入口位於“關於應用”。

- **檢查更新**：檢查 GitHub 最新正式 Release，跳過預發佈和草稿。
- **自動檢查更新**：應用運行期間每 24 小時檢查一次，也可隨時手動檢查；檢查或下載失敗後會延後重試。
- **自動下載更新**：啓用後自動下載已發現的新版，不會因此直接退出應用。
- **安裝更新**：校驗通過後，由更新窗口引導安裝並重新啟動。

更新包使用獨立簽名和完整性校驗。下載或校驗失敗會停止安裝，可重試或前往 GitHub 下載。

## 快取與資料

“連接與配置 → 快取與資料”提供三類資訊與維護入口：

- **TMDB 快取**：查看資料、海報和人物圖片佔用、按中繼資料語言統計的空間，以及已入庫作品關聯的 TMDB 人物數量。可清空 TMDB 快取，也可通過“TMDB 快取清理”按項目選擇清理。
- **Emby 快取**：查看媒體記錄、劇集檔案、合集與 Emby 圖片數量。清理會移除這些本地記錄、Emby 圖片、觀看記錄快取及相關索引，保留 TMDB 接口資料、海報和人物頭像檔案。之後可從首頁重新同步；連接與登入資訊保留，伺服器資料不變。
- **本地搜索索引**：根據本地 Emby 作品、合集和人物資料自動維護。搜索異常時可直接重建，無需聯網，不修改觀看記錄。

“TMDB 快取清理”支持清理其他語言的影視與分集中繼資料、海報偏好之外的語言圖片，以及不再被片單或媒體庫引用的快取。清理其他語言中繼資料時保留當前語言、海報路徑和圖片；清理圖片時保留當前偏好及回退所需圖片，中文海報同時包含簡繁兩種字形。

連續 7 天未被引用且未新增或更新的快取，會在引用關係完整、應用空閒時自動清理；其他語言資料不會僅因切換語言就被自動刪除。清空 TMDB 快取後可從首頁重新同步榜單與媒體庫，圖片仍按需下載。正常使用無需手動重建索引。

## 備份與恢復

在“連接與配置 → 備份與恢復”將配置與本地資料導出為加密備份，或從備份檔案恢復。

| 備份內容 | 包含的資料 |
| --- | --- |
| TMDB API 配置 | API 地址與 API Key |
| MoviePilot API 配置 | 服務地址與 API 令牌 |
| TMDB 榜單 | 榜單內容、自建片單、片單設定與核心榜單範圍 |
| TMDB 快取 | 影視與人物資料、海報和人物圖片 |
| Emby 配置 | 伺服器、線路、當前帳號、登入令牌及觀看記錄 |
| Emby 快取 | 媒體庫、合集、分集及 Emby 圖片 |
| 使用偏好 | 界面、片單與中繼資料語言，海報語言、名稱映射、播放器及顯示偏好 |

導出時可自由勾選需要備份的內容。設定至少 8 個字符的密碼並確認後，保存為 `.ecbackup` 檔案。

恢復時選擇備份檔案、輸入密碼，僅展示檔案中包含的項目，並可再次選擇恢復範圍。配置、榜單與使用偏好會替換本機對應內容；快取合併，搜索索引自動更新。

核心榜單所選級別與單獨勾選、排除項隨“TMDB 榜單”一起備份和恢復。僅恢復榜單時，其他未選中的語言、播放與顯示偏好保持不變。

觀看記錄隨 Emby 配置備份，僅包含當前帳號的觀看狀態和播放進度。恢復時核對伺服器與帳號，並保留較新的觀看記錄。

備份包含 API 密鑰與登入資訊，請妥善保管檔案和密碼。
